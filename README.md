# Meharena Trucking — Company Website

A one-page website for Meharena Trucking. When a shipper lands here they should know three things in ten seconds: what we haul, where we run, and how to get a quote. The page is built to do exactly that.

## What's on it

- **Hero + services** — full truckload, partial/LTL, dedicated lanes, and expedited, in plain language a busy shipper actually reads.
- **Service area** — where the trucks run, plus the three promises that matter: on-time focus, one call to a real person, live updates.
- **Why shippers stay** — straight answers, early warnings, careful freight handling.
- **Quote-request form that works** — name, contact, route, date, weight, and freight details, with validation. On submit it builds a clean request summary with a reference number right on the page.
- **Dispatch contact block** ready for the real phone and email.

## Before this goes live for real

Two marked placeholders to replace in `index.html`: the dispatch phone/email, and one line in the service-area section to match the exact lanes the company runs. The quote form is front-end only right now — it shows the requester a summary but doesn't send anything yet. Connecting it means pointing it at the company's email, a form service, or a small dispatch backend.

## Running it

Plain HTML, CSS, and JavaScript. Open `index.html`, or host the folder on any static host (GitHub Pages works).
